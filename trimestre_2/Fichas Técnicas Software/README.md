## 📌 Presentación del Módulo

Esta carpeta reúne la especificación técnica, valoración de costos y análisis de licenciamiento del software utilizado para el desarrollo, gestión de datos y administración del **Sistema de Información de Inventario de Materias Primas** de la microempresa **Villa de Guaduas**.

Su propósito es documentar las licencias requeridas para los entornos de desarrollo y operación, evaluando alternativas comerciales (Microsoft) frente a opciones de uso libre para optimizar el presupuesto del proyecto formativo.

---

## 🎯 Componente Metodológico

### 1. Alcance de las Fichas de Software

Las fichas técnicas archivadas en este módulo abarcan la cotización y justificación del licenciamiento clave:

* **Microsoft Visual Studio:** Entorno de desarrollo integrado (IDE) para la construcción, depuración y compilación del software (evaluación de licencias Community vs. Professional).
* **Microsoft SQL Server:** Sistema Gestor de Base de Datos (SGBD) para la persistencia, seguridad e integridad del inventario de materias primas (evaluación de licencias Express vs. Standard per Core/CAL).
* **Microsoft Office (Office 365 / LTSC):** Suite de ofimática para la gestión documental, análisis de datos en Excel, generación de informes y soporte administrativo del proyecto.

| Software | Tipo de Licencia | Propósito en el Proyecto |

| **Microsoft Office** | 365 Business / LTSC | Elaboración de reportes, documentación administrativa y control de insumos. |

## 📐 Estándar de Documentación

Cada ficha técnica detalla el nombre del producto, versión, tipo de licencia, costos estimados, requerimientos de sistema e impacto directo en los **Requerimientos No Funcionales** (RNF-04 Seguridad, RNF-05 Integridad de datos y RNF-10 Cumplimiento normativo).
